# sereneAI.CCOS — Programme Documentation

sereneAI.CCOS (Serenade AI / sereneAI Contact Centre Operating System) is a commercial
**Contact Centre Operating System**: the operational layer that sits above existing contact
centre systems, connects them together, and gives users one coherent place to work.

Strategic principle (approved, non-negotiable baseline):

> **Integrate First. Replace Second. Automate Third. Transform Fourth.**

## Working rules

1. The Project Bible is the baseline for every recommendation, design, plan and build instruction.
2. Challenge decisions where appropriate; never silently ignore approved direction.
3. Protect MVP scope aggressively (MoSCoW; see scope definition).
4. Configuration before customisation. One core platform, many customer deployments.
5. Every change to approved direction must be recorded in the Decision Register in the Bible.
